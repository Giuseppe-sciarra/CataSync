The Categories tab now does just three things: add, delete and reorder the shop's categories.

### Changes
- **New categories are always main categories** and go at the end of the list. The “Inside” choice is gone, and the API ignores a parent category too.
- **Site menu and Category mappings removed from the tab**: CataSync no longer touches the site menu. The mu-plugin stays optional and is set up only on the site (*Appearance → Menu categorie*); mappings already saved keep working in imports.
- Subcategories the site already has, made in WordPress, are still shown under their category; the delete confirmation and the note under the list mention subcategories only when there are some.
- The message for a 403 from the menu mu-plugin no longer blames only the REST key: it also mentions a firewall or security plugin blocking the address.
