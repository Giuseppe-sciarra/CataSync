First public release of CataSync, the self-hosted portal that builds WooCommerce product sheets from an EAN or a manufacturer code.

### Highlights
- Web search through your own SearXNG: one to three spaced-out queries per code, in the language and country of the sheets, only to the engines that work on codes.
- When the engines block (CAPTCHA, "too many requests"), the code is postponed and retried by itself instead of ending up "not found".
- Friendly page reading: `robots.txt` respected, one request every 1.5 seconds per site, anti-bot protections recognised and skipped, never bypassed.
- A **Why?** button on every miss: the queries, the engines that answered or blocked, the sites opened and what happened on each.
- Only pages that state the code are trusted; category and search pages are recognised and the product link is followed.
- Sheets in Italian, English, French, German or Spanish, translated with your own LibreTranslate; interface in Italian, English, French and German.
- Publishing through the WooCommerce REST API: nothing to install on the shops, products already on the site are updated, never duplicated.
- Portal name, logo and favicon uploadable from the panel; light and dark theme.
