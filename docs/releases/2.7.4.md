A paid search API as backup for SearXNG, a second read with the browser, and no more searches for lines that are not codes.

### Highlights
- **Brave Search API as backup for SearXNG** (*Settings → Automatic web search*): when SearXNG's engines block or don't find the code, the same query goes to the Brave API, which never blocks ($5 per thousand searches, $5 of free credit every month). Optional: without a key only SearXNG is used. It also covers the manufacturer-code search.
- **Second read with the browser** for right-but-poor pages (no description or a single photo): Chrome reopens them after JavaScript and the richer read is kept. Pages that refused us are never reopened.
- With a paid engine, rounds and pauses no longer apply: they only exist for engines read without an agreement.
- Lines that are not codes (commands, descriptions pasted by mistake) are no longer searched; from «8801643654689 SAMSUNG» the EAN is searched.
- The Google Programmable Search note now says the API is closed to new customers and shuts down on 1 January 2027.
