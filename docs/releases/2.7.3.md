Poor product sheets get completed with the manufacturer code.

### Highlights
- **Completion with the manufacturer code.** When the pages found with the EAN give a poor sheet (no real description or a single photo), the portal also searches the manufacturer code those pages carry and merges the new pages that confirm it. Example 8801643654689: chironpro.com (French, no description, one photo) is completed by Rexel and Sonepar (Italian, with description and photos). Kits with another model in the name are discarded. In the diary these searches and pages are marked «with the manufacturer code».
- The manufacturer code confirms a page even without the «/EU» suffix; a wholesaler's brand abbreviation («Manufacturer: SMG») matches the full name («Samsung»).
- All-caps names become readable («Esterne EHS split R32 (monofase) 4.»); specs no longer repeat codes and brand.
- A poor sheet is kept in memory for 2 days instead of 30, so the next search tries again.
- Sonepar photos were discarded as placeholders because of «default.aspx» in their path: fixed.
- Translation: words left in the source language («extérieur») are translated on their own and kept only if the round trip confirms them.
