Icecat's «GTIN can not be found» is handled as «not in the catalogue», and Icecat is asked again by brand and manufacturer code.

### Highlights
- Icecat answers HTTP 400 «The GTIN can not be found» when it doesn't have the EAN: it was shown as a failure, now it reads «Icecat doesn't have this EAN in its catalogue» and the web search takes over.
- **Icecat by manufacturer code**: when the EAN is missing but the web search finds brand and manufacturer code, Icecat is asked again by brand + code; if found, the Icecat sheet becomes the base and the web fills the gaps.
- The test in *Settings → Icecat* also accepts brand and manufacturer code.
