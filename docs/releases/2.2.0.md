Categories can now be renamed from CataSync, and subcategories are back.

### Highlights
- **Rename** in the Categories tab: edit the name in place (Enter saves, Esc cancels); it changes on the site and in the portal. The slug stays the same, so links to the category keep working, and an unsaved order is not lost.
- **Subcategories again**: with “Inside” a new category is created inside another one, at the end of its siblings.
- Category names with “&” no longer show up as “&amp;”, and duplicate checks compare the real names.
