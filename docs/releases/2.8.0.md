Icecat is back as the first source, with one account for the whole portal.

### Highlights
- **Icecat first** (*Settings → Icecat*: username, API access token, Content access token, stored encrypted). Every EAN of every client is asked to Icecat first: complete sheet → the web search doesn't start; partial → the web fills the gaps; missing (or Full Icecat only, or outside the subscription's vertical) → the web searches.
- Texts Icecat only has in English are translated with LibreTranslate, with the same round-trip check used for web pages.
- **Test an EAN on Icecat** in Settings shows what comes back or why it's missing, to check coverage before moving to Full Icecat.
- Icecat also runs first in the batch test and in the client's source comparison; in the «Why?» diary it is the first row with its outcome.
